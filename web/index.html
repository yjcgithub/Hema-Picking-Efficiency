接口 Cookie

入库口径与上传 xlsx 完全一致（按「拣货开始时间」的日期集合覆盖 / 新增）：
· 由后端带 Cookie 请求拣货单接口，需要先保存一次 Cookie（登录态过期后需重新粘贴）。
· Cookie 失效时页面会提示：打开盒马工作台页面，点右下角插件面板里的「立即同步」手动同步一次，脚本会重新读取并保存 Cookie。
· 取数条件：开始 / 结束日期是手动与自动获取共用的日期区间，默认当天；页面开着跨过 0 点（24 点）会自动翻到新的一天并同步到服务端（手动改过的历史区间不会被覆盖）。单日区间若已过期，服务端会自动顺延为当天，因此浏览器没开也不会一直抓旧日期；多日区间按指定值固定不变。
· 分页：index 是页码（0 起，倒序第一页 = 最新），总页数 = ceil(总条数 totalNum ÷ 每页条数)，拿到第一页即确定；取数时弹窗与顶栏显示「第 x / N 页」。每页条数可设置（单日约 4000 条）。
· 增量获取：从最新页往回取，遇到「整页拣货单号都已入库」即停，只把新增明细并入已有数据集，重复拉取不会翻倍。
· 自动获取：服务端按设置的间隔自动增量获取页面「取数条件」的日期区间（默认当天；需已保存 Cookie，且服务端保持运行）。可设置每日执行时段（如 07:00 ~ 22:30），时段外自动暂停；时段的开始 / 结束时刻各额外强制获取一次，不吃间隔排期（仍受 60 秒冷却约束）。
· 手动获取：顶栏「手动获取」按钮立即按页面「取数条件」的日期区间增量获取，不用打开本弹窗。
· 防风控：翻页之间随机停顿 300~900ms；自动间隔加 ±15% 抖动（避免固定时刻规律打点）；连续失败按指数退避重试（间隔翻倍，最多 60 分钟），成功后立即恢复正常间隔。手动 / 自动 / 脚本同步共用 60 秒取数冷却，冷却中「手动获取」按钮禁用并显示倒计时。首页角标只显示自动获取开关状态。
· 油猴脚本（推荐）：UMS 登录态是 HttpOnly Cookie，脚本读不到，所以脚本改为在本页面内用登录态取数后回传 —— 安装 userscript/hema-pick-sync.user.js 后，后端不再需要 Cookie，也能自动同步（保持 ums 页面标签开着即可）。
